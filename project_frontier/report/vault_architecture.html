Project Frontier · Fabrik decode accelerator

The DRAM-on-logic system, as currently modeled

Fabrik is not a processor with memory attached. It is an array of independent vault columns — each compute tile bonded face-to-face to its own 3D-DRAM stack, with hundreds of channels landing directly in local buffers. Every number below is either measured in this project's simulations or carried from a sourced device spec; the distinction is marked.

2 · What actually moves during one decode step

Three traffic classes leave the stacks every token, and they do not achieve the same fraction of peak bandwidth. Treating them as interchangeable bytes is the single largest source of error in a memory-centric model — which is why each is priced separately here, from Ramulator measurements rather than a flat assumption.

Power splits DRAM array ≈55%, vertical interface 9%, compute 7%, SRAM 6%, static 9% — a memory-centric machine spends its energy in the memory array, and any honest model must say so.
